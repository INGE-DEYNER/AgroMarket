# Iconos de AgroMarket

Este directorio contiene los iconos SVG reales para el proyecto AgroMarket.

## Estructura

- **categories/**: Iconos de categorías de productos
- **navigation/**: Iconos de navegación
- **actions/**: Iconos de acciones
- **status/**: Iconos de estado
- **social/**: Iconos de redes sociales
- **payment/**: Iconos de métodos de pago

## Uso

Importar iconos directamente desde este directorio:

```jsx
import HomeIcon from '@/assets/icons/navigation/home.svg';
```
